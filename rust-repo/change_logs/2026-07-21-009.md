# Migration Log 2026-07-21-009

Status: Completed

## Scope

Propagate the memory transport protocol through replica domain, persistence,
protobuf, master allocation, and client conversion as the compatibility
foundation for upstream `b996ac4b` scoring.

## Changes

- Add protobuf `ReplicaDescriptor.protocol` as field 14.
- Add `ReplicaDescriptor.protocol` with serde defaulting for old snapshots and
  oplog payloads.
- Preserve protocol across clone and proto round trips.
- Populate allocated memory replicas from their owning `Segment.protocol`.
- Decode legacy catalog replicas and non-memory LocalDisk replicas with an
  empty protocol.
- Preserve the field in the client proto-to-domain adapter.

## Compatibility

- Existing protobuf field numbers are unchanged; old peers omit field 14 and
  decode to an empty string.
- Legacy serialized replicas without `protocol` decode successfully to an
  empty string.
- Replica status/type values, endpoint aliases, allocation order, and snapshot
  tuple layouts are unchanged.

## Test-driven verification

- Confirmed the proto round-trip test failed before implementation because
  both domain and wire protocol fields were absent.
- Core, master, and client test targets compile with the new field.
- Proto round-trip and allocator tests assert protocol preservation.
