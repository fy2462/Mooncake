## Local disk watermark eviction

### Upstream

- `f5bc1c15` adds proactive disk watermark eviction.
- Default high and low watermarks are `0.90` and `0.80`.
- Eviction is enabled by default and supports the `MOONCAKE_OFFLOAD_*` and
  compatibility `MOONCAKE_DISK_*` environment variables.

### Rust migration

- Run proactive eviction from the client storage heartbeat even when no
  offload task is returned.
- Select FIFO victims after usage crosses the high watermark and evict down to
  the low watermark.
- Notify the master before deleting local replica files.
- Restore selected FIFO victims when the master notification fails.

## SSD offload publication consistency

### Upstream

- `a5b938cd` fixes the SSD offload publish-before-commit race.

### Rust migration

- Commit local object data before publishing its local-disk replica.
- Remove locally committed objects when publication to the master fails.
- Keep disk-space eviction as a prepare, publish, then commit transaction.

## Compatibility

- Existing environment variable names and their upstream fallbacks are
  preserved.
- Watermark eviction requires `LocalStorageConfig::enable_eviction`.
- No persisted storage format is introduced; local offload data remains an
  ephemeral cache.
