## Client health and metrics HTTP configuration

### Upstream

- `12304b92` exposes optional client health/metrics HTTP configuration to
  Python.
- The feature is disabled by default and uses port `9300` when enabled.
- An occupied HTTP port does not fail client setup.

### Rust migration

- Add public `ClientHttpConfig` and the backward-compatible
  `MooncakeClient::create_with_http_config` constructor.
- Own the Axum server task in `MooncakeClient`, prevent duplicate starts, and
  stop it during `tear_down_all`.
- Serve `/health` from shared client lifecycle state and `/metrics` in
  Prometheus text format.
- Validate enabled port zero before client bootstrap; listener bind failures
  are logged and client setup continues without endpoints.
- Append PyO3 arguments `enable_client_http_server=false` and
  `client_http_port=9300` after all existing arguments.
- Enable PyO3 auto-initialization only for Rust test builds so existing Python
  error-path tests execute instead of failing at link/runtime setup.
