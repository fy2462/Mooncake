## Local-disk state snapshot persistence

### Upstream

- `525c7305` persists local-disk state in master snapshots so it survives a
  master restart or HA promotion.

### Rust migration

- Persist each client's ID, offloading-enabled flag, pending offloading object
  queue, and total SSD capacity in standalone storage-backend snapshots.
- Restore that state when constructing the standalone master service.
- Encode and restore the same state through HA catalog snapshots and hot
  standby promotion.
- Keep `promotion_objects` runtime-only and initialize it empty after restore.
- Sort client and object identifiers before serialization where deterministic
  snapshot output is required.

## Compatibility

- Standalone snapshots created before this migration remain readable through a
  default-empty local-disk field.
- HA local-disk entries without the trailing SSD-capacity field remain readable
  and restore capacity as zero.
- New HA snapshots append SSD capacity in the layout used by the corresponding
  upstream C++ snapshot format.
