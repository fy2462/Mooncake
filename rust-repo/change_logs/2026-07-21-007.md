# Refactor Log 2026-07-21-007

## Scope

Replace allocator strategy output collections with one owned allocation state
value while preserving partial allocation and strategy behavior.

## Rust refactor

- Add private `AllocationPlan` state containing the requested replica count,
  allocated replicas, and used segment names.
- Move completion, remaining-count, segment deduplication, and replica insertion
  behind named plan operations.
- Pass one mutable plan through random, free-ratio, SSD free-ratio, and
  local-first strategies instead of separate replica and used-name outputs.
- Consume the plan into the existing `Vec<ReplicaDescriptor>` public result.

## Compatibility

- Preferred segments are still attempted before the selected strategy.
- Random start index, retry limit, candidate sampling, and fallback calls are
  unchanged.
- Replica insertion order and segment-name deduplication are unchanged.
- Requests that cannot be fully satisfied still return all replicas allocated
  so far rather than failing or rolling them back.
- Exclusions and single-replica local-first behavior are unchanged.
