# Refactor Log 2026-07-21-005

Status: Completed

## Scope

Encapsulate client lifecycle flags and offload-server bookkeeping in focused
Rust state types without changing observable behavior.

## Rust refactor

- Replace the shutdown `RwLock<bool>` field with `ShutdownState`.
- Replace direct ping-health `AtomicBool` access with `HealthState`.
- Replace direct remount `Arc<AtomicBool>` access with cloneable
  `RemountState` operations.
- Group the offload task handle, port, and RPC address into
  `OffloadServerState`.
- Make all lifecycle state fields private to the client module.

## Compatibility

- Shutdown still takes the write lock before unregistering memory.
- Ping and remount atomics retain `SeqCst` ordering.
- Remount status is cleared on the same non-storage and spawned-task completion
  paths as before; this refactor does not add cancellation cleanup semantics.
- Offload startup still records handle, port, then address, and teardown still
  aborts and removes the task handle without clearing the published endpoint.
- Public lifecycle methods and their return values are unchanged.
